# MM-Lounge

A modular and extensible deep learning toolkit for experimenting with computer vision and sequence modeling tasks, built using Python and Jupyter Notebooks.

## Overview

**MM-Lounge** is a research-focused project providing implementations and blueprints for modern deep learning models, particularly in computer vision and sequence data analysis. This repository is ideal for students, researchers, and developers who want to understand and rapidly prototype state-of-the-art neural networks.

## Features

- **Blueprint Deep Learning Functions:**  
  Core utilities for building, training, and evaluating neural networks, easy to extend and adapt for various tasks.

- **Model Implementations:**  
  - **LSTM:** Recurrent architectures for sequential data, such as text or time series.
  - **Vision Transformers (ViT):** Transformer-based models for image classification and related vision challenges.
  - **Image Query:** Utilities and demos for image-based queries, showcasing information retrieval and search capabilities.

- **Jupyter Notebook-centric:**  
  Interactive notebooks for experimentation, visualization, and reproducible research.

- **Modular Design:**  
  Each major model and experiment lives in its own organized notebook or module, making it simple to swap, modify, or extend components.


## note : the project is still under development, to create plugins of each model to be used seamlessly anywhere. please contact the maintainer for contributing.
